# out-traveler

국민여행조사·지원금 데이터 기반 지역경제 상관관계 분석

## 프로젝트 개요

문화체육관광부 국민여행조사 원자료(2024~2025)와 여행 지원금 데이터를 결합 분석하여, 지역별 방문 집중도와 실제 지출 수준의 관계를 파악하는 프로젝트입니다. 방문·지출 조합(4분면)별로 지원금이 어떤 효과를 낼 가능성이 높은지 분석하고, 지원금 배분 우선순위 판단 근거를 제공하는 것을 목표로 합니다. 분석 결과는 챗봇 시스템을 통해 사용자에게 전달합니다.

## 필요성

- 지자체 여행 지원사업은 선착순 구조로 운영되어, 수요 증가에 따라 유의미한 지역에 지원금 분배가 필요함 (예: 제주관광공사 여행 지원 프로모션, 7억 6천만원 규모 예산이 7일 만에 조기 소진)
- 단순 방문객 수만으로는 지역별 관광 활성화 수준을 판단하는 데 한계가 있어, 방문 집중도와 실제 지출 수준을 함께 분석할 필요가 있음
- 기존 여행 지원금 정보와 국민여행조사 데이터를 연계하여, 데이터 기반 지원 우선순위 판단 근거 마련

## 주요 분석 내용

1. **지역별 방문 집중도 × 지출 수준 분석**: 가중치(WT_DOM)를 적용해 시·도별 방문 집중도와 지출 수준(외식·숙박·교통·관람료 등)을 비교 분석
2. **방문 집중도 × 지출 수준 기반 지역 유형화**: ① 방문 높음·지출 낮음 ② 방문 높음·지출 높음 ③ 방문 낮음·지출 높음 ④ 방문 낮음·지출 낮음 4개 유형으로 분류
3. **여행 지원금과 지출 수준의 관계 분석**: 상관분석 및 다중회귀분석을 통해 지원금과 여행 지출 간 관계 확인
4. **지원금 배분 우선순위 지역 도출**: 방문·지출·기존 지원금 정보를 종합해 지원 필요성이 높은 지역 선별

## 데이터 구성

- `data/raw/` — 전처리 전 원본 데이터
  - `2024_resized.csv`, `2025_resized.csv` — 국민여행조사 연도별 리사이징 데이터
  - `combined_2024_2025.csv` — 2024~2025년 통합 원본 (약 10만 건)
- `data/processed/` — 전처리 완료 데이터

## 기술 스택

- Python 3.9+
- pandas, numpy — 데이터 처리
- matplotlib, seaborn — 시각화
- streamlit — 결과 제공(챗봇/대시보드)
- uv — 프로젝트/의존성 관리

## 기대효과

- **분석 관점**: 지역별 방문 집중도와 지출 수준을 시각화하여 지역별 관광 소비 특성 파악
- **사용자 관점**: 원하는 지역 입력 시 여행지원금 내역과 방문 집중도 시각화 결과 제공
- **정책 관점**: 관광 활성화 사업 및 지원 대상 지역 검토를 위한 데이터 기반 근거 제공
