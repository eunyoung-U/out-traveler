# out-traveler

국민여행조사·지방재정 세출데이터 기반 지역경제 상관관계 분석

## 프로젝트 개요

문화체육관광부 국민여행조사 원자료(2023~2025)와 지방재정 세출현황(관광·문화재 예산) 데이터를 결합 분석하여, 지역별 방문 집중도·지출 수준·지자체 예산 간의 상관관계를 파악하는 프로젝트입니다. 분석은 두 개의 독립된 트랙으로 진행됩니다.

- **트랙1 (연간 상관관계 분석)**: 시/도 단위로 방문·지출·지자체 예산 간 상관관계를 검증 (가설1, 가설2)
- **트랙2 (월별 실시간 조회)**: 챗봇에서 지역 선택 시 해당 지역·해당 월의 혼잡도와 1인 평균 지출을 제공

## 필요성

- 지자체 여행 지원사업은 선착순 구조로 운영되어, 수요 증가에 따라 유의미한 지역에 예산 배분이 필요함 (예: 제주관광공사 여행 지원 프로모션, 7억 6천만원 규모 예산이 7일 만에 조기 소진)
- 단순 방문객 수만으로는 지역별 관광 활성화 수준을 판단하는 데 한계가 있어, 방문 집중도·지출 수준·기존 예산 배분을 함께 분석할 필요가 있음
- 국민여행조사와 지방재정 세출데이터를 연계하여, 데이터 기반 예산 배분 우선순위 판단 근거 마련

## 분석 계획 (트랙1 — 연간 상관관계 분석)

1. **가설1**: 시/도 단위에서 방문 횟수와 총 지출 간 상관관계 검증 (Pearson/Spearman 상관분석)
2. **가설2**: 관광·문화재 분야 지자체 자체재원 예산과 방문량 간 상관관계 검증 (시/도 단위, 시/군/구 단위 각각 비교)
3. **시군구 예산 편차 분석**: 광역시 내 구/군 간 예산 편차를 확인하여, 세부 지역 단위 예산 배분 시사점 도출

## 분석 계획 (트랙2 — 월별 실시간 조회)

- 지역·월 선택 시 1인 평균 지출(WT_DOM 가중평균) 및 방문 혼잡도를 제공하는 기능 구현 예정
- 표본 수가 적은 지역·월 조합에는 신뢰도 경고 문구를 조건부로 노출할 예정
- 2023~2025년 데이터를 연도 구분 없이 통합(풀링)하여 집계할 예정

## 데이터 구성

- `data/raw/` — 전처리 전 원본 데이터
  - `combined_2023_2024_2025.csv` — 국민여행조사 2023~2025 통합 원본 (약 15만 6천 건)
  - `track_2_dataset_2023_2024_2025.csv` — 지역×월별 방문건수/1인 평균지출 집계 데이터
  - `regional_expenditure_2023_2024_2025.csv` — 지자체별 관광·문화재 세출현황 원본 (약 4만 8천 건)
- `data/processed/` — 전처리 완료 데이터
  - `team_combined_2023_2024_2025_processed.csv` — 국민여행조사 팀 최종 통합 전처리본 (분석 시 사용)
  - `team_regional_expenditure_2023_2024_2025_processed.csv` — 세출데이터 팀 최종 통합 전처리본 (분석 시 사용)
  - `이름_*_processed.csv` — 팀원별 개인 전처리 결과물 (검증·비교용으로 보존)

## 기술 스택

- Python 3.9+
- pandas, numpy — 데이터 처리
- matplotlib, seaborn — 팀원별 EDA/분석 단계 시각화
- Tableau — 최종 분석 결과 대시보드/시각화
- streamlit — 챗봇 서비스 제공
- uv — 프로젝트/의존성 관리 (uv.lock은 git 미추적, 로컬에서만 유지)

## 기대효과

- **분석 관점**: 지역별 방문·지출·예산의 관계를 시각화하여 지역별 관광 소비 특성 및 예산 배분 효율성 파악
- **사용자 관점**: 원하는 지역·월 선택 시 혼잡도와 1인 평균 지출 정보를 챗봇으로 즉시 제공
- **정책 관점**: 지역(구/군) 단위의 세부 예산 배분 우선순위 판단을 위한 데이터 기반 근거 제공
